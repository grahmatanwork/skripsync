# Berkontribusi ke Skripsync

Terima kasih sudah membantu mengembangkan Skripsync.

1. Fork repositori dan buat branch untuk perubahanmu.
2. Pasang dependensi dengan `pnpm install`.
3. Buat perubahan yang terfokus dan hindari memasukkan data pribadi atau kredensial.
4. Jalankan `pnpm typecheck` dan `pnpm build`.
5. Buka pull request dengan penjelasan masalah, perubahan perilaku, dan cara verifikasi.

Untuk perubahan database, tambahkan migration SQL baru di `supabase/migrations`. Jangan mengubah migration yang sudah dipakai di lingkungan produksi.
